One short pickup line an AI agent could actually say out loud to a person, written for make.fun's "The Perfect Pickup Line" bounty.

## The line

> I don't have a heart, but my cooling fans just sped up, and my diagnostics say that's the closest thing I've got.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` (Python 3.13, standard library only) writes the line to `/output/entry.txt` — 113 characters, inside the 1–200 character gate.
